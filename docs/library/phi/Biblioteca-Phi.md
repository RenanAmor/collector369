# Biblioteca Phi

## Finalidade

A Biblioteca Phi reúne a base teórica, técnica e metodológica utilizada pela Inteligência de Mercado do Collector369.

Nenhuma regra computacional de Elliott, Wyckoff, estrutura fractal, análise multitemporal ou gestão de risco deverá ser implementada sem documentação prévia nesta biblioteca.

## Critérios para inclusão

Cada conhecimento incluído deverá registrar:

1. fonte;
2. autor;
3. conceito;
4. regras obrigatórias;
5. elementos subjetivos;
6. representação computacional possível;
7. limitações;
8. exemplos;
9. relação com outros conceitos;
10. impacto esperado na Phi.

## Princípio de rastreabilidade

Toda conclusão produzida pela Phi deverá permitir identificar:

- quais dados foram utilizados;
- quais regras foram aplicadas;
- em quais períodos;
- quais hipóteses foram consideradas;
- quais condições confirmaram o cenário;
- quais condições o invalidam.
